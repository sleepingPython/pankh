# Pankh (पंख) Website Files

This package contains the complete website files for **Pankh (पंख)**.

## File Structure
- `index.html` - Main HTML markup with SEO metadata, layout, and interactive JavaScript form logic.
- `styles.css` - Full CSS stylesheet featuring mobile-first responsive layout, Google Fonts integration, and warm Indian-inspired palette.

## Assets Required in Your Folder
Please make sure the following image files exist in the same directory as `index.html`:
1. `pankh-wing.png` - Logo image.
2. `pankh-book-cover.png` - Cover image for your first book release.

## Hosting & Deployment
You can host these files on any static hosting service, such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, or traditional cPanel web hosting.
